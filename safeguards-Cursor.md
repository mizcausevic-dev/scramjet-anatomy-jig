# Safeguards

The plate is a schematic side elevation. It is safe to publish because it does not provide a build procedure, a fuel schedule, a test point, or a performance number someone could mistake for a flight clearance.

- Shock angles are composed so the forebody shock meets the cowl lip and the reflected train dies ahead of the pylons. They are not a design solution.
- The wall-pressure polyline is a shape with no units.
- Bone arrows show direction of force on the vehicle. They are not a thrust measurement.
- No form, no analytics, no third-party font request.
- Pages is a static file serve from `gh-pages`. No GitHub Action, no build token, no secret in the repository.

Do not add a number to the plate without a source, a unit, and the conditions that number was taken under.
